# AURIS simulator

Open hybrid ear-surgery simulator (DC15) of the **AURIS** Marie Skłodowska-Curie Doctoral
Network (*Advanced Ultra-precise Robotic Inner-ear Surgery*), hosted by Inria (DEFROST team,
Université de Lille) and built on the [SOFA](https://www.sofa-framework.org) framework.

Together with the AURIS digital twin (DC14), it supports testing and comparison of robotic
instruments and cochlear-implantation strategies, for research and training.

!!! warning "Early development"
    Version 0.1.0 contains the skeleton, a **synthetic** example scene and draft exchange
    formats. Parameters in the examples are placeholders, not anatomical or validated values.
